# Website Audit Tool

Standalone website audit app for quick customer website reviews.

It uses the shared `packages/website-audit-core` module so improvements can also flow back into the phone-led AI Business Audit app.

## Run

```bash
npm start
```

Open:

```text
http://localhost:3100
```

## Current Scope

- Single-page website review
- Conversion, trust, SEO, copy, and technical signal checks
- Category scores, priority opportunities, and action plan
- JSON download and browser print/PDF

## Keep Us On Track

This should become either a lead magnet, a paid mini-audit, or an internal sales qualifier. Do not add crawler depth, payments, accounts, or CRM sync until the first usable version has been tested with real prospects.
